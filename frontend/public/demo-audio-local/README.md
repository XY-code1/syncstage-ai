# 本地评审授权音频

本目录仅允许放置主办方或权利人**明确授权**用于本地赛事评审的 MP3、M4A、OGG 或 WAV 文件。

- 音频只用于本地赛事 Demo，不得发布、传播或改作。
- 音频文件已被 `.gitignore` 忽略，**不得提交到 Git**。
- 文件名只使用无隐私的短标识，不得包含姓名、手机号、账号、密钥或其他用户隐私。
- 不得放置 QMC 等受保护格式，不得转换、解密或绕过 VIP、登录、DRM 与地域限制。
- 获得授权后，再在 `frontend/src/data/localDemoAudioManifest.ts` 中为对应曲目填写从 `/demo-audio-local/` 开始的相对 URL。

未提供合法本地音源时，页面不会显示失效的播放键，只提供跳转主办方给出的 QQ 音乐官方参考歌单。
