# SyncStage 路线图与当前限制

## 当前比赛版本

- 聚焦 QQ音乐演出详情页内的“AI找同行”。
- 主链路截止于双向确认后的临时同行房间。
- 输入、授权范围、安全条件都会动态影响候选、排除结果、评分和解释。
- 不包含信息流、开放私信、支付、真实票务或复杂后台。
- 不包含演出后回忆卡或共同回忆歌单。

## 当前限制

- 使用虚构演出与匿名用户的脱敏 Mock 数据。
- 未接入 QQ音乐官方内部 API、真实账号和实时消息系统。
- 对方确认由 Demo 时序模拟。
- SQLite 只用于本地开发验证。

## 后续计划

获得正式接口与合规授权后替换 `TMEDataProvider`，保持 Agent、评分和前端契约不变；再进行真实用户研究、安全评估和多人实时状态验证。
