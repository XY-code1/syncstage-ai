# QQ音乐「一起去现场」3 分钟演示脚本

## 0:00–0:25｜QQ音乐演出详情

打开默认页，展示歌手、时间、地点、热门歌曲和安全提示。说明这是 QQ音乐演出详情概念页，新入口是“AI找同行”。

话术：QQ音乐拥有用户真实的听歌、收藏、歌单、歌手和关注演出资产，因此能够在“同一场演出”里找到音乐偏好可验证的同行者。

## 0:25–0:45｜音乐画像授权

进入授权弹窗，展示收藏歌曲、常听歌手、歌单标签、关注演出和近期播放。先演示“暂不授权”的停止状态，再重新选择并授权。

强调：本作品为参赛概念Demo，当前使用模拟数据，未调用QQ音乐官方内部API。

## 0:45–1:15｜Agent 对话及需求确认

输入：“想找两个也喜欢《夜航的信》和星野回声的人一起候场，交流慢热一点，只在公开场合见面。”

点击“让 Agent 理解需求”，在同一页面展示并调整结构化歌曲、歌手、人数、同行目的、交流方式和安全硬条件，然后确认执行。

## 1:15–1:50｜Agent 执行任务

展示真实工具轨迹：解析需求、读取授权画像、读取演出、检索同场候选、安全过滤、四维排序、组队与依据生成。说明输出会随输入和授权范围改变，安全条件由确定性程序处理，不交给模型自由判断。

## 1:50–2:25｜匹配结果与邀请

展示候选人的同场演出、共同歌曲与歌手、音乐画像证据、同行目的、交流方式、安全条件、差异提醒、四维评分和数据来源。打开“查看 Agent 依据”，展示授权字段、工具轨迹、排除原因和 Mock 声明。发送双向确认邀请。

## 2:25–3:00｜临时同行房间

等待“对方已查看 → 双方确认”，进入房间。展示双方确认状态、AI 音乐破冰卡、候场任务、公开集合点、默认关闭的位置共享、退出、拉黑和举报。

收束：房间只服务演出前和候场期间，活动结束 24 小时后自动归档；演示到房间建立成功结束。
